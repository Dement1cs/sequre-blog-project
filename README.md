# Secure Blog Project

## How to Run the Project

1. Clone the repository:
  ```bash
  git clone https://github.com/Dement1cs/sequre-blog-project.git
  cd sequre-blog-project
  ```
2 Install dependencies:
  ```bash
  npm install
  ```
3 Run the secure version:
  ```bash
  git checkout secure
  node app.js
  ```

Application will be available at:
http://localhost:3000
